# Editra — Sai Kiran Reddy

Portfolio site, live at **https://teameditra03.github.io/editra/**

## Managing videos (no GitHub needed)

Open **https://teameditra03.github.io/editra/#admin** (or press `Ctrl + Shift + A` on the site).

- Only the owner can make changes: the panel needs an access key from the Teameditra03 GitHub account (limited to this repo, Contents: Read and write). Follow the on-screen steps once per device; the key stays saved in that browser. Use **Lock** on shared computers.
- Add a video (upload a file up to 95 MB, or paste a YouTube / Drive / Vimeo / Instagram link), choose where it goes, and press **Add to list**.
- Reorder (drag ☰ or ↑ ↓), edit, or remove videos, and change the showreel.
- Press **Publish changes**. The site updates for visitors in about 1–2 minutes.

Videos and the showreel are stored in `videos.json`. The previous version of the site (and its old video files) is kept on the `old-site` branch.
